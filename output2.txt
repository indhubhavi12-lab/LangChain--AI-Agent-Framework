User Question: What is LangGraph in LangChain?

Tool Answer:
LangGraph is a library built on top of LangChain that allows you to build stateful, multi-step applications using Large Language Models (LLMs).

Here's a clear breakdown:

**What it is:**
LangGraph lets you define your AI application as a **graph** — where:
- **Nodes** = individual steps or actions (e.g., call an LLM, run a tool, process data)
- **Edges** = the flow between steps (including conditional branching)

**Why it's useful:**
- Standard LangChain chains run in a straight line (A → B → C).
- LangGraph adds **loops, branching, and memory** — so your agent can make decisions, retry steps, or take different paths based on results.

**Key Features:**
1. **Stateful** – keeps track of data across multiple steps
2. **Cycles** – supports loops (e.g., an agent that keeps trying until it gets a good answer)
3. **Human-in-the-loop** – can pause and wait for user input mid-execution
4. **Persistent memory** – can save and reload state across sessions

**Simple Example Flow:**
```
START → [LLM decides action] → [Run Tool] → [Check result] → loop back or END
```

**In short:** LangGraph is the framework used to build reliable, controllable AI agents in LangChain that can plan, act, observe, and repeat — just like a real intelligent agent would.
