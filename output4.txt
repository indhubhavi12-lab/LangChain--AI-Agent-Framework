Simple QA Tool
========================================
Question: What is LangGraph in LangChain?

Answer:
LangGraph is a library built on top of LangChain for building stateful, multi-step AI agents
using a graph-based structure.

Key Concepts:
- Nodes: Each node is a step — calling an LLM, running a tool, or processing data
- Edges: Define the flow between steps, including conditional branching and loops
- State: Data is passed and updated across all steps in the graph

Why use LangGraph?
- Standard LangChain runs linearly (A → B → C)
- LangGraph adds loops, branching, memory, and human-in-the-loop support
- Ideal for building production-grade, reliable AI agents
