User Query:
What is LangGraph in LangChain?

Agent Response:
LangGraph is a library built on top of LangChain for building stateful, multi-step AI agents
using a graph-based structure.

- Nodes represent individual steps (LLM calls, tool use, data processing)
- Edges control the flow between steps, including loops and conditional branching
- State is maintained and passed across all steps throughout execution

Unlike basic LangChain chains that run linearly, LangGraph supports cycles, memory,
human-in-the-loop pauses, and complex decision trees — making it the recommended
framework for building production-grade AI agents.
